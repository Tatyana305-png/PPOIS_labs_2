О компиляторе

Модель компилятора SimpleTanchiK

Описание

Программная система для трансляции исходного кода на простом языке программирования в машинный код. Компилятор поддерживает поэтапную компиляцию с возможностью сохранения промежуточных состояний.

Этапы компиляции

1
Лексический анализ

Разбор исходного кода на токены. Определяет ключевые слова, идентификаторы, операторы, числа, строки и разделители.

2
Синтаксический анализ

Построение абстрактного синтаксического дерева (AST) на основе полученных токенов.

3
Оптимизация

Улучшение кода: свертка констант, удаление мертвого кода, распространение констант, уменьшение силы операций.

4
Генерация кода

Создание машинного кода (ассемблероподобные инструкции) на основе оптимизированного AST.

Уровни оптимизации

  • Уровень 0 - Без оптимизации
  • Уровень 1 - Базовая оптимизация (свертка констант, удаление мертвого кода)
  • Уровень 2 - Полная оптимизация (все оптимизации)

Технологии

  • Backend: Python 3, Flask
  • Frontend: HTML5, CSS3, JavaScript
  • Архитектура: Клиент-серверное приложение

Контрольные вопросы

1. Что такое распределённые информационные системы?

Распределённая ИС — это система, компоненты которой находятся на разных компьютерах, взаимодействующих через сеть.

2. Как работает клиент-серверное приложение?

Клиент отправляет запросы серверу, сервер обрабатывает их и возвращает ответ. В нашем приложении клиент (браузер) отправляет код на сервер Flask, который компилирует его и возвращает результаты.

3. Что такое протокол HTTP?

HTTP — протокол передачи гипертекста, основанный на запросах и ответах. Методы: GET (получение), POST (отправка данных), PUT (обновление), DELETE (удаление).

4. Как работает Flask?

Flask — микрофреймворк для Python. Он обрабатывает маршруты, поддерживает шаблоны Jinja2, сессии и расширения.

5. Что такое HTML/CSS?

HTML — язык разметки для структуры страницы. CSS — каскадные таблицы стилей для оформления внешнего вида.
