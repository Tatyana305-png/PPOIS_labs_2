Возможности компилятора

Лексический анализ

Разбор исходного кода на токены с определением типов (ключевые слова, идентификаторы, операторы, числа)

Синтаксический анализ

Построение абстрактного синтаксического дерева (AST) на основе токенов

Оптимизация

Свертка констант, удаление мертвого кода, распространение констант, уменьшение силы операций

Генерация кода

Создание машинного кода (ассемблероподобные инструкции) на основе оптимизированного AST

Пример кода

int x = 5 + 3;
int y = 10;
int result = x * y;

if (result > 50) {
    result = result - 10;
} else {
    result = result + 10;
}

while (result > 0) {
    result = result - 1;
}

return result;
